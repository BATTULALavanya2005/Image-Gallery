Nature Gallery
  A sleek, responsive, and interactive photo gallery featuring a custom-built lightbox navigation system. This project demonstrates clean HTML5 structure, modern CSS Grid layouts, and vanilla JavaScript for DOM manipulation.

 Features
      Responsive Grid Layout: Utilizes CSS Grid with auto-fill and minmax to ensure the gallery looks great on desktops, tablets, and mobile devices. 
      Custom Lightbox: A fully functional modal window to view images in high resolution without leaving the page. 
      Navigation Controls: Intuitive "Previous" and "Next" buttons within the lightbox for seamless browsing. 
      Smooth Animations: Hover effects on gallery items and fade-in transitions for the lightbox provide a polished user experience.  
      Click-to-Dismiss: Close the lightbox by clicking the close button or anywhere outside the image. 
  
Technologies Used
     HTML5: Semantic markup for structure.  
     CSS3: Modern layout techniques (Grid, Flexbox), media queries for responsiveness, and keyframe animations.  
     JavaScript (ES6+): Vanilla JS for event handling and dynamic state management.
